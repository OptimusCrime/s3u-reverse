Whole-game evidence of verified functions

Every verified function passed its differential tests (and usually an emulator spec). Whole-game evidence means the game also called our replacement during a whole-game check (a recorded game replayed, or a savegame run) whose trace was identical to the original's (re/whole_game_calls.csv). "Tests only": installed and counted, but never called in any check. "May run inside": the count can miss calls that come straight from our own replacements of the listed functions (they bypass the counting thunk), so these might have run anyway; unconfirmed.
